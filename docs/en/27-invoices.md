# Module: Invoices

## What it does

Invoice management for the mosque. Admin can upload PDF files, and authenticated users can download them.

## Database

**Table:** `facturas`
**Fields:** titulo, fecha, archivo_pdf (path string), notas

PDFs stored in `storage/app/public/facturas/`.

## Backend

**Controller:** `Admin\FacturasController`
**Model:** `Factura`

**Controller methods:**
- `index()` — list invoices
- `store(Request)` — create with PDF upload
- `update(Request, $id)` — update (with optional new PDF)
- `destroy($id)` — delete invoice and its PDF
- `download(Factura $factura)` — download PDF

**Model accessor:**
- `getArchivoUrlAttribute()` — returns public PDF URL

## Admin frontend

**Page:** `Admin/Facturas.jsx`
- Invoice table
- Form with PDF file input
- Direct download button

## Public frontend

**Page:** `Facturas.jsx` (requires auth)
- Invoice list with download links
- Read-only

## Technical decisions

- **File upload:** Uses Laravel's `public` disk. PDF is stored with unique name generated by `$request->file('archivo_pdf')->store('facturas', 'public')`.
- **`archivoUrl` accessor:** Model exposes a public URL so the frontend can download without exposing the real server path.
- **Deletion:** When deleting an invoice, the PDF file is also removed from disk.
